Neural Network Cheatsheet

A small map of the concepts covered so far: network structure, layers, activations, and output/loss/metrics.

1. Network Structure

Sequential

step -> step -> step

  • Pro: simplest to understand and implement.
  • Con: no branches or shortcuts.

Skip / residual

Later output also receives an earlier value.

  • Pro: can converge faster; shorter gradient path.
  • Con: needs shape matching/projection.

Branch

One input flows into multiple paths.

  • Pro: paths can learn different features.
  • Con: harder to reason about than a chain.

Merge / concat

Multiple paths are combined again.

  • Pro: combines different representations.
  • Con: can increase size/parameters.

Multi-head output

Shared body, separate outputs for separate tasks.

  • Pro: one model can learn related tasks.
  • Con: losses may compete.

2. Layer

Linear

z = W x + b

  • Pro: clear matrix math.
  • Con: ignores spatial structure if images are flattened.

Conv2d

Filters over image grids.

  • Pro: uses local image structure.
  • Con: less direct than plain matrices.

BatchNorm

Normalizes activations.

  • Pro: can stabilize training.
  • Con: behaves differently in train/eval mode.

Dropout

Randomly masks activations during training.

  • Pro: can reduce overfitting.
  • Con: may slow training.

Pooling

Reduces spatial size.

  • Pro: cheaper and more compact.
  • Con: discards detail.

3. Activation

Sigmoid

Squashes to 0..1.

  • Pro: intuitive and historically important.
  • Con: gradients can become tiny.

ReLU

max(0, z)

  • Pro: simple and trains well.
  • Con: negative side is fully zero.

Tanh

Squashes to -1..1.

  • Pro: centered around zero.
  • Con: still saturates.

LeakyReLU

ReLU with small negative slope.

  • Pro: keeps some negative-side gradient.
  • Con: adds a slope choice.

GELU / SiLU

Smooth modern activations.

  • Pro: often strong in modern networks.
  • Con: less transparent than ReLU.

4. Output / Loss / Metric

Sigmoid output + mean squared error

Matrix example.

  • Pro: easy to derive by hand.
  • Con: less standard for single-label classification.

Logits + cross entropy loss

PyTorch example.

  • Pro: standard for class prediction.
  • Con: hides softmax/log details inside the loss.

Softmax

exp(score) / sum(exp(scores))

  • Pro: makes classes compete.
  • Con: probabilities can become overconfident.

Accuracy

Argmax correctness, not training loss.

  • Pro: simple final performance metric.
  • Con: ignores confidence.

Confusion matrix

Expected class vs predicted class.

  • Pro: shows which classes are confused.
  • Con: more verbose than one number.
